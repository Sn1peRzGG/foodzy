# Foodzy Client Application

Foodzy is a food delivery and ordering web application that provides a seamless experience for discovering meals, managing a shopping cart, building a wishlist, and tracking food orders in real time.

## Features

* **Interactive Menu & Category Browsing:** Discover food items filtering by dynamic categories.
* **Smart Shopping Cart:** Easy add, remove, and instant price/quantity updates.
* **User Profiles & Auth:** Secure authentication flow combined with custom user avatars.
* **Personal Wishlist:** Save your favorite dishes to order them later with a single click.
* **Fully Responsive UI:** Optimized for perfect pixel view from smartphones to widescreen desktops.
* **Strict Code Quality:** Pre-configured with ESLint and Prettier for error-free production code.

## Tech Stack

* **Framework:** Next.js 16 (App Router)
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **Linter & Formatter:** ESLint, Prettier
